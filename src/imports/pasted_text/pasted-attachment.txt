Project Overview

Build a modern, professional web application called CargoBridge (name can be changed) for managing goods transported from China to Algeria through individual transport agents.

The system is used by two business owners:

- China Admin (creates goods records and assigns them to agents)
- Algeria Admin (tracks expected goods and confirms arrivals)

The transportation model is not traditional shipping. Goods are transported through agents/travelers who carry goods from China to Algeria.

The objective of the system is to provide complete visibility over:

- What goods are expected
- Which agent is responsible
- Goods status
- Estimated departure and arrival dates
- Communication between both sides
- Scan-based tracking using camera functionality

Development Strategy

The application must be designed in two phases.

Phase 1

Frontend only.

Requirements:

- Use React + TypeScript
- Use Tailwind CSS
- Use shadcn/ui components
- Store all data in Local Storage
- Simulate backend operations
- Create realistic mock data
- Build all screens and workflows
- Ensure every feature works using local state and Local Storage

Phase 2

Backend migration.

The UI must be designed so that Local Storage can later be replaced by:

- Supabase
- PostgreSQL
- Authentication
- Realtime updates
- File storage

Important:

Create a clean service layer abstraction so that data sources can easily be swapped from Local Storage to Supabase without changing the UI.

Example:

- goodsService
- agentService
- chatService
- userService

Language Requirements

This is a critical requirement.

The system must be designed with multilingual support from the beginning.

Default language:

- Arabic (RTL)

Secondary language:

- French (LTR)

Requirements:

- Arabic must be the default language throughout the application.
- The entire UI should be optimized for RTL layouts.
- Users can switch between Arabic and French from the settings or header.
- All labels, navigation items, forms, tables, notifications, and messages must support localization.
- Build the system using a proper i18n architecture so additional languages can be added later.
- All mock data and UI examples should primarily use Arabic content.
